# Telegram Send Skill

Отправляет файлы и текстовые сообщения пользователю Telegram через Bot API.

## Требования

Переменные окружения (в `.env` или в конфиге opencode):

| Переменная | Назначение |
|-----------|------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | ID получателя (число) |

## Триггеры

Пользователь говорит фразы:
- "отправь мне в телеграм"
- "отправь в телегу"
- "отправь файл в телеграм"
- "скинь в телеграм"
- "пошли в телеграм"
- "send to telegram"

## Инструкция для агента

### 1. Проверить переменные

Проверь что `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` установлены.
Если нет — скажи пользователю: "Укажи TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID".

### 2. Определить тип отправки

**Если у тебя есть готовый файл** (агент его создал или он существует):
→ Используй `sendDocument` с multipart/form-data

**Если нужно просто текст** (короткое сообщение):
→ Используй `sendMessage`

### 3. Отправить файл

```bash
curl -s -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendDocument" \
  -F "chat_id=${TELEGRAM_CHAT_ID}" \
  -F "document=@путь/к/файлу.md" \
  -F "caption=необязательная подпись"
```

**Подпись (caption)** — опционально. Можно указать, чтобы пояснить что за файл. Максимум 1024 символа.

### 4. Отправить текст

```bash
curl -s -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage" \
  -d "chat_id=${TELEGRAM_CHAT_ID}" \
  -d "text=текст сообщения" \
  -d "parse_mode=Markdown"
```

`parse_mode` поддерживает `Markdown` и `HTML`.

### 5. Проверить ответ

Успех → приходит `{"ok": true, "result": {"message_id": ...}}`.
Ошибка → выведи пользователю текст ошибки из `response.description`.

### 6. Подтверждение пользователю

После успешной отправки скажи: "Готово, файл отправлен в Telegram."

## Пример сценария

1. Агент создаёт `report.md` в рабочей директории
2. Пользователь: "отправь мне в телеграм"
3. Скилл активируется → агент читает инструкцию выше
4. Агент выполняет curl с `sendDocument` и `@report.md`
5. Сообщает: "✅ report.md отправлен в Telegram"

## Безопасность

- Храни TELEGRAM_BOT_TOKEN в .env или secrets, не в коде
- Chat ID проверяется сервером Telegram — только указанный пользователь получит файл
- curl вызывается с `-s` (silent), ничего не выводит лишнего
