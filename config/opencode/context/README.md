# Context directory

This directory contains optional reusable project standards and technical references.

Agents must not preload it wholesale. Project `AGENTS.md`, scoped skills and files explicitly supplied by the current task take precedence. `ContextScout` discovers individual files here only when they materially constrain the current task.

The former OAC context-management framework and OpenAgents-repository documentation are intentionally removed from the active runtime; they remain available in the archive branch.
